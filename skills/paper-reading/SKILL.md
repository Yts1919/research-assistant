# 论文精读 (paper-reading)

## 工作流

1. 拿到论文来源（PDF 路径 / DOI / 标题 / 粘贴的文本）。
2. 用 `tools/paper.py` 提取内容：
   - PDF：`python tools/paper.py --pdf 论文.pdf --out 论文.txt`（全文保存到 out，终端打印元数据 + 预览）
   - DOI：`python tools/paper.py --doi 10.xxxx`（取元数据 + 摘要）
3. 读全文（用 read 工具分段读），按下方结构产出精读卡片。
4. 把卡片写入右侧「精读」悬浮窗（比检索面板更宽，约 680px）：
   - 把卡片写成 JSON 文件 `card.json`，格式：`{"title":"...", "authors":"...", "venue":"...", "year":"...", "doi":"...", "sections":[{"heading":"一句话总结","body":"..."}, ...]}`；
   - `python tools/paper.py --write-card --card card.json`（自动写入 config 的 panel.paper_json_path）。

## 精读卡片结构

```
一句话总结
论证链重建（问题 → 前人局限 → 核心洞见 → 设计 → 证据 → 实际支撑的结论）
方法（核心方法/模型/实验设计 + 输入输出 + 关键假设）
主要结果（关键发现 + 每个实验「验证了什么 / 什么更强结论未被证明」）
作者明确承认的局限（只列作者自己说的）
批判性分析（缺对照 / 替代解释 / 失败情形 / 可做的验证实验）
```

## 长文策略

- 先读「摘要 → 结论 → 各图表标题 → 方法段」，再按需精读某节；
- 分段读，不要试图一次读完整篇；每段读完后更新认知。

## 原则

- 只基于原文，不编造；信息不足处标注「未提及」；
- 区分「作者承认的局限」与「你的批判」，不要混在一起；
- 结论用 hedged 表述，不夸大。
