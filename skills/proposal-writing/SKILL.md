# 开题/方案写作 (proposal-writing)

## 核心：proposal-first（先立框架，再成文）

1. **先确认要论证什么**，再写：
   - 研究问题是什么？
   - 为什么重要（意义）？
   - 现有工作没解决什么（空白）？
   - 你打算怎么做（内容+方法+技术路线）？
   - 预期成果与创新点？
2. 把这些写成「一句话论证 + 章节契约」，向用户复述确认。

## 结构（开题报告标准）

1. 研究背景与意义
2. 国内外研究现状（**用检索到的真实文献**，不编造）
3. 研究内容与目标
4. 研究方法与技术路线
5. 创新点
6. 进度安排
7. 预期成果
8. 参考文献（真实）

## 原则

- 「研究现状」先检索真实文献（`tools/search.py`）再写，引用真实；
- 技术路线可以用流程图（Graphviz）表示；
- 结论措辞克制，不夸大预期成果。

## 与「开题」悬浮窗的交互

- 面板提供：题目/方向输入、补充要求、生成方案、导出、清空；各节内容可点击标题折叠/展开；
- 用户点「生成方案」把【题目+要求】复制给 AI；AI 完成方案后写成 JSON 写回面板：
  ```bash
  python tools/panel.py --panel proposal --file proposal_out.json
  ```
  JSON 结构：`{"title":"…","sections":[{"title":"研究背景与意义","content":"…"}],"references":["…"]}`
- 面板轮询 `/proposal-panel.json` 展示开题框架 + 各节内容 + 参考文献；「导出 Markdown」下载 `开题方案.md`；「清空」复制指令给 AI 执行 `panel.py --panel proposal --clear`。
